## 公司介绍

沸点网络是亿级 DAU 内容社区平台，已上市。商业化收入以广告与会员为主，商业化中台是今年战略重点，正扩编。

## 岗位职责

1. 负责商业化产品（广告投放系统 / 会员体系）的策略设计与迭代，对 eCPM、续费率等核心指标负责；
2. 拆解商业化漏斗，定位收入瓶颈，设计可实验验证的优化方案；
3. 平衡商业化与用户体验，建立护栏指标机制；
4. 与内容、算法、销售团队协作，推进商业化项目落地；
5. 跟踪行业商业化玩法（广告、会员、直播打赏），输出策略建议。

## 任职要求

1. 3 年以上互联网产品经验，有商业化 / 广告 / 增长产品经验者优先；
2. 数据敏感，熟练使用 SQL，具备扎实的实验设计能力；
3. 逻辑清晰，能在多方目标冲突下推动决策；
4. 有内容社区或平台型产品经验者优先；
5. 加分：熟悉广告计费模型（oCPC / CPM / CPC）与会员经济。
