# career-grill —— 逼问式梳理求职方向与筛选标准

把「我想找个好工作」逼问成**可执行的求职筛选标准**。一次只梳理一个求职方向。

## 铁律：先读事实源，别凭记忆

开工**先读**（都在工作区根下）：
- `CONTEXT.md` —— 个人背景、**筛选硬规则**、**目标方向与优先级**、术语表（唯一事实源，随时可能更新）。
- `AGENTS.md` —— 工作区规矩与红线。
- `01-profile/master-resume.md`、`01-profile/_internal/strategy.md` —— 已有主简历和对内策略笔记；里面已有答案的问题不问。

**本文档不写任何硬规则数字**——薪资下限、城市、年限全部以 CONTEXT.md 为准，避免两处打架。

## 访谈纪律（最重要）

- **一次只问一个问题**。问完等回答，再问下一个。一次抛一串问题会把用户问懵。
- **每个问题都给推荐答案**：基于已知信息给出"我建议是 X，因为 Y"，让用户确认或纠正，比开放题快得多。
- **能自己查到的不问**：CONTEXT.md、已有主简历里写过的先读再问，只问文件里没有的。
- **追问模糊词**：用户说"想找个好的"、"有发展的"、"稳定点"，必须逼成可判断的标准
  （薪资下限是多少？什么叫有发展——晋升、技能成长还是业务在涨？稳定是指不裁员还是不加班？
  这一条是硬门槛还是加分项？）。
- **沉淀术语**：访谈中出现的行业黑话、岗位别名、技能简称，随手写进 CONTEXT.md「术语表」，之后统一用这些词。

## 问题清单

按 [`references/question-bank.md`](references/question-bank.md) 的顺序走（有依赖关系，别乱序）。
核心七组：求职动机与约束 → 硬门槛 → 目标岗位定义 → 命脉卖点与证据 → 短板与排除信号 → 目标公司与搜索词 → 渠道策略。

## 主流程（每个方向一次）

1. **访谈**：按问题清单一次一问走完七组，每组答完当场复述结论让用户确认。
   - **完成判据**：七组每组都有明确结论或明确的"不设线"，无模糊词残留。
2. **写四件产出**（见下节），写完向用户报告四个文件路径。
   - **完成判据**：四件全部写完，互相之间数字口径一致；CONTEXT.md 与策略笔记里的硬规则一字不差。
3. **收尾提醒**：告诉用户 `strategy.md` 是对内文件**绝不外发**；从今天起每日筛选就按这套标准执行；
   标准想改随时说，改动会记进「已对齐决策」。

## 产出（每方向四件，全部写完才算梳理完）

1. **对外主简历框架** `01-profile/master-resume.md`（可外发版）。结构：
   - 职业定位一句话（我是谁、能解决什么问题）；
   - 核心卖点 2-3 条，每条带可验证证据（项目/数据/作品）；
   - 经历骨架（公司/职位/时间段/一行一条的事实点）。

   ⚠️ 红线（不可删）：**绝不编造简历和面试内容**。不虚构公司、项目、职位、数字；简历定制只做真实经历的重组、取舍与措辞对齐。这条标注"不可删"。
   另：**绝不自动投递、打招呼或发消息给 HR**。对外动作默认逐个先经用户确认；用户本轮明确授权"合适的直接投"则本轮可放开，但逐一回报投了什么；跨轮不自动延续。
   薪资底线、短板应对、真实离职原因**不进**这份文件。

2. **对内策略笔记** `01-profile/_internal/strategy.md`——第一行写"内部文件，不外发"，内容：
   硬约束一句话锚定、命脉卖点与证据、短板应对话术、薪资底线（标注**绝不外发**）、
   目标公司锚点、空的关键词迭代表。
   写完提醒用户：**这份不外发**。

3. **CONTEXT.md 更新**：
   - 「一、个人背景」：首次梳理时填写（当前状态、为什么换工作只写"敏感/不敏感"标注，不展开敏感细节）。
   - 「三、筛选硬规则」：本次确认的通用硬门槛（城市/远程、薪资下限、行业排除、公司规模、坐班/出差、JD 排除信号）。
     已有内容冲突时向用户确认后更新。
   - 「四、目标方向与优先级」：本方向状态从"待梳理"改为"在找"，补优先级和文件链接。
   - 「五、术语表」：本次新沉淀的术语。
   - 「六、已对齐决策」：以上每处变更记一条，带日期。

4. **初始搜索关键词**：把访谈得出的搜索词（岗位词/技能词/行业词 + 排除词）
   写进 `strategy.md` 关键词迭代表的 R1 行（效果列留空，跑过首轮筛选后回填）。

## 什么时候重新 grill

- 筛了几轮发现标准明显不对（推的岗全不想去/池子里根本没有这种岗）
  → 带着 `02-jobs/job-ledger.csv` 台账数据重新走一遍**硬门槛**和**命脉卖点**两部分；
- 用户情况变了（被裁/涨薪/换城市/家庭变化）→ 增量更新，改动记进「已对齐决策」带日期。

## 什么时候不用本流程

- 对某类岗位的行情没底（市场上什么价、要什么人）→ `skills/market-mapping/SKILL.md`。
- 已有明确目标 JD、要按它改简历 → `skills/resume-tailor/SKILL.md`。
- 每天的筛选、投递、台账、日报执行 → `skills/jobhunt-daily/SKILL.md`（本流程只定标准，不做执行）。
- 面试准备与复盘 → `skills/interview-prep/SKILL.md`。
