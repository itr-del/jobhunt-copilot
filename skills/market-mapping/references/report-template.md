# report-template.md —— 市场调研报告模板（market-mapping 第 4 步用）

> 落点：`runtime/reports/market-<方向>-YYYY-MM-DD.md`；有 `lark-cli` 可同步飞书云文档。
> **所有数字必须来自本轮真实取样并注明来源与日期；取样不足就标"样本量不足"，不编数字。**

---

```markdown
# 市场调研报告：<目标方向>（YYYY-MM-DD）

## 样本说明（必填，缺了报告不成立）

- 取样日期：YYYY-MM-DD
- 取样渠道与样本量：boss N 条 / 猎聘 N 条 / 其他 N 条（粗去重后合计 N 条）
- 搜索词："<实际用的搜索词>"（城市：<范围>）
- 口径备注：技能词频基于 JD 全文 / 仅摘要；样本量不足的章节已标 ⚠️

## 一、市场供给

- 在招岗位量：各渠道分别 N 条（去重后 N 条）
- 城市分布：

| 城市 | 岗位数 | 占比 |
| --- | --- | --- |
| <城市> | N | N% |

- 一句话结论：这个方向的池子是大是小、集中在哪。

## 二、薪资水位（分位表，按 JD 要求年限分层）

| 年限层 | 样本数 | P25 | P50 | P75 |
| --- | --- | --- | --- | --- |
| 1-3 年 | N | <月薪或年薪，注明口径> | | |
| 3-5 年 | N | | | |
| 5 年以上 | N | | | |

- 口径：按 JD 标注区间的中点计算；标注"面议"的样本不计入分位（占比 N%，已注明）。
- 与 CONTEXT.md 薪资下限对照：下限处于市场 P__ 位置 → 偏紧 / 合理 / 偏松。
- ⚠️ 样本量不足的层标"仅供参考"，不硬算分位。

## 三、技能关键词频率 Top 榜（Top N=10~15）

| 排名 | 关键词 | 出现频次 / 占比 | 用户情况（已具备 / 缺失 / 错位） |
| --- | --- | --- | --- |
| 1 | <技能词> | N 次（N%） | 已具备（证据见主简历） |

- 「错位」= 用户会做但简历用词与 JD 常用词不一致，列为措辞对齐点。

## 四、目标公司盘点

| 公司 | 在招岗 | 画像（规模/业务/阶段，公开信息） | 内推可达性 |
| --- | --- | --- | --- |
| <公司> | <岗位> | <一句话> | 可达（经谁）/ 不可达 / 待确认 |

- 每行对应样本或台账里真实见过的岗位，不写"听说在招"。

## 五、差距与行动建议

1. **需补技能**（高频但缺失）：<技能> → <补救建议：短期可补 / 长期绕行 / 换方向规避>
2. **下轮搜索词调整**：加 <词>、减 <词>（依据第三章词频与台账拒绝模式）
3. **简历关键词对齐**：把 <JD 常用词> 对齐进主简历（走 resume-tailor 执行，只重组真实经历）

## 六、给 CONTEXT.md 的更新建议（只是建议，改了要用户确认）

| 建议改动 | 依据（本报告章节） | 影响 |
| --- | --- | --- |
| 例：薪资下限从 X 调到 Y | 第二章 P25 已高于现下限 | 池子放大 N 条 |

- 用户确认的改动：更新 CONTEXT.md，并在「已对齐决策」记一条带日期；未确认的原样保留。

---

*本报告所有数字来自上方"样本说明"所述取样，仅代表取样时点的平台在招情况；不作任何就业结果承诺。*
```
